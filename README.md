# Triangulum Daily

[English](https://github.com/qianqian5774/triangulum-daily3albums/blob/main/README.en.md) | 中文

每天九张专辑。
三个时段，每次三张。
不追热点，不刷榜单，只给一天留几个听见别处的入口。🎧

## 🌗 这是什么

**Triangulum Daily** 是一个每天推荐九张专辑的音乐发现项目。

它最初来自一个很私人的想法：给自己一个每天听专辑的入口，让听歌从算法信息流里稍微退出来一点。这里没有无限滑动，也不试图不断猜中你的喜好。每天的九张专辑分三次出现，像一份有节奏的音乐日历。

站点每天自动生成内容，按北京时间逐步解锁，并把过去的推荐保留为静态归档。你可以每天打开看一眼，也可以隔一段时间回来翻看以前出现过的唱片。

## ✨ 它会做什么

每天，网站会给出九张专辑推荐。一天分为三个时段，每个时段解锁三张：

| 时间  | 内容                   |
| ----- | ---------------------- |
| 08:00 | 第一时段，解锁三张专辑 |
| 12:30 | 第二时段，解锁三张专辑 |
| 16:00 | 第三时段，解锁三张专辑 |

08:00 以前，Today Page 保持正常的 Offline State。到达下一个时段时，新的三张专辑会自然出现。

这不是一个追求“最热门”“最权威”或“最懂你”的推荐系统。它更像一份每日听觉提示：有时熟悉，有时意外，希望每次都能离惯常路径稍微远一点。

## 🧭 为什么做它

现在听音乐很方便，但发现音乐仍然很容易变窄。

你可能一直回到同一批歌手、同一种情绪或同一套推荐逻辑。Triangulum Daily 想做的事情很简单：每天提供一点轻微的偏离。

它关心的是：

- 每次只解锁三张，减少同一时刻的信息噪音。
- 尽量避开过于熟悉、过于主流的结果。
- 保留每天的归档，让推荐形成一条可以回看的时间线。
- 让音乐发现更像散步，而不是刷屏。

## 🕰 每日节奏

Triangulum Daily 使用北京时间作为一天的节奏。

```text
00:00 - 07:59   Offline State
08:00 - 12:29   第一时段
12:30 - 15:59   第二时段
16:00 - 23:59   第三时段
```

三个时段不是为了制造神秘感，而是为了让站点保持清楚、有限的节奏。

## 🗂 网站内容

- **Today Page**：当天九张专辑，按三个时段逐步解锁。
- **Treatment Viewer**：从 Album Card 打开的覆盖式专辑浏览器，不是独立详情路由。
- **Archive Page**：过去每天出现过的静态推荐。
- **Share Card**：根据当前已经解锁的时段生成分享卡。
- **Ambient Overlay**：用于沉浸或待机浏览的覆盖层。

## ⚙️ 它背后如何运行

每天清晨，Python generator 会读取配置和外部音乐数据，生成九张推荐与静态 JSON；React/Vite UI 随后构建为静态资源，并由 GitHub Pages 发布。

```text
外部音乐数据 → Python generator → Static JSON → React/Vite UI → GitHub Pages
```

访客打开页面时不需要实时后端，也不会由浏览器调用外部音乐 API 生成推荐。
