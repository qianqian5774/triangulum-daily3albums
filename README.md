# Triangulum Daily

[中文](./README.zh-CN.md) · [Visit Triangulum Daily](https://triangulumdaily.space/)

Triangulum Daily is a small record shop for discovering nine albums each day. Step through the door, browse the records, and spend time with a selection that has a beginning and an end.

## Nine albums, three openings

The shop follows Beijing time (BJT, UTC+8). Three albums become available at **08:00**, six by **12:30**, and all nine by **16:00**. Before 08:00, the daily selection is closed; recent records remain available in History.

## Inside the shop

**Today** presents the current day's records as they open. **History** lets you revisit recent daily selections. Select a record to open the **Treatment Viewer**, which gives the album room for a closer look without leaving the shop.

Each day's selection is prepared before publication. The website serves its pages, album information, and cover images as static content.
