# Triangulum Daily

[English](./README.md) · [访问 Triangulum Daily](https://triangulumdaily.space/)

Triangulum Daily 是一间每天带来九张专辑的唱片店。推门进入，翻看唱片，在一份有始有终的每日精选中停留片刻。

## 九张专辑，三次开放

唱片店遵循北京时间（BJT，UTC+8）：**08:00** 开放前三张，**12:30** 开放至六张，**16:00** 开放全部九张。08:00 之前，当日精选尚未开放；仍可在 History 回看近期唱片。

## 走进唱片店

**Today** 随时段呈现今天已经开放的唱片。**History** 可以回看近期的每日精选。选中一张唱片会打开 **Treatment Viewer**，在店内更仔细地了解它。

每天的精选在发布前准备完成。网站以静态内容提供页面、专辑信息与封面图片。
